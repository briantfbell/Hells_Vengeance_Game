# Party exploration sprites

Created with the built-in imagegen tool. Style reference: `freya-sheet.png`. Original Freya sheet retained; the six additional character sheets are listed below.

Open `../Party Sprite Studio.html` to inspect front, right, back, mirrored left, and idle/walking playback. Open `../Kintargo Playable Art Test.html` and choose Play as to test any character in the street. The original `Hell's Bubbies.html` is unchanged.

Each sheet contains nine exploration poses: three facings by idle/step A/step B. Left is mirrored right. PNGs retain alpha transparency. Source images are roughly 1K by 1.6K; use `sprite-frames.json` or `sprite-frames.js` for exact frame source bounds rather than assuming perfectly equal thirds. These metadata files align feet and avoid frame bleed without changing the generated PNGs. Final attack and casting animation sheets are outside this exploration set.

## Validation

All 63 frames (including Freya) contain visible sprites. Browser checks confirmed all seven sheets load, all four facings render, every character moves in Kintargo, mobile layouts fit, local HTML files load, and the browser reports no script errors. The sheet grids and rendered studio were visually inspected.
